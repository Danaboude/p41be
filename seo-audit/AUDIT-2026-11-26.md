# Full SEO audit: 2026-11-26

Live site www.p41.be after PR #8 (Time Study films). Public pages only; /admin, /api and
/academy/access not crawled. Method: raw HTML fetch (what bots without JavaScript see),
headless render (claude-seo `render_page.py`), `agentic_check.py --ua-matrix`, live checks of
the sitemap and structured data, and a throttled mobile load test in Edge (Playwright, about
1.6 Mbit/s, 150 ms latency, 4x CPU slowdown). Google PageSpeed could not run: the public keyless
quota was used up and there is no API key.

## Action plan

### High
- **H1. Menu links Google cannot follow.** Header and footer links are `<a (click)="…">` without
  `href` (`shared/layout/header/header.html`, `footer/footer.html`). Google only follows links with
  an `href`, so the menu passes no link value and pages are found mostly through the sitemap.
  Keyboard users cannot reach them either. Fix: add `href="/time-study"` etc. (or `routerLink`)
  to every menu link. The "Home" item is also highlighted on every page.

### Medium
- **M1. /contact loads slowly (LCP 7.5 s).** The hero background (`hero-background.webp`, 406 KB)
  is the largest element. Compress it further or use a lighter image on this page.
- **M2. /academy layout shift (CLS 0.16).** Content moves while course cards load. Reserve the
  height of the featured course block.
- **M3. Short pages.** Blog posts (~350 words) and /contact (212 words).
- **M4. Unsourced claims.** "At least 10% within 3 months", "100+ companies since 1995".

### Low
- **L1. Separate film pages** if video search results matter (see above).
- **L2. Dutch has no URLs of its own.**
- **L3. Google API key** for PageSpeed and CrUX field data in future audits, and submit
  `/sitemap.xml` in Search Console so the video entries are picked up.
- **L4. Film content.** The price film shows a "PDT CODE" column header and the line balance film
  a "TIME TMU" header; blur these per the no-licensed-standards rule.
